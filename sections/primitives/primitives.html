Layout Primitives

Seven CSS-only layout primitives with a data-* API that consumes the Fibonacci spacing/radius scale and semantic surface tokens: Box, Stack, Inline, Center, Frame, Cover, and Switcher. Zero JavaScript, no new public tokens. A spacing or gap utility on the same element always wins, so you can always drop down a layer.

Box — a padded, optionally skinned surface

.vd-box consolidates padding, background, radius, and an optional border behind one element.

secondary / md
primary / lg
bordered
<div class="vd-box" data-pad="fib-13" data-bg="secondary" data-round="md">…</div>
<div class="vd-box" data-pad="fib-13" data-round="md" data-border>…</div>
AttributeValuesEffect
data-pad0, fib-1…fib-55Padding from the Fibonacci spacing scale.
data-bgprimary / secondary / tertiary / dark / darkerSemantic surface background.
data-roundnone / sm / md / lg / xl / 2xl / fullBorder radius (mirrors .vd-rounded-*).
data-border(present)1px solid --vd-border-color.

Inline — a wrapping row

.vd-inline is a horizontal flex row that wraps by default — toolbars, tag rows, button groups.

Alpha Bravo Charlie Delta 
<div class="vd-inline" data-gap="fib-5" data-justify="between">
  <span>Alpha</span> <span>Bravo</span> …
</div>
AttributeValuesEffect
data-gap0, fib-1…fib-55Gap between items.
data-alignstart / center / end / baseline / stretchCross-axis alignment (default center).
data-justifystart / center / end / between / around / evenlyMain-axis distribution.
data-wrapnowrapDisable wrapping (wrap is the default).
Center — center a column and/or its content

.vd-center centers itself horizontally within a width cap (data-max) and can center its content (data-axis).

A 377px column, auto-centered in its parent.
<div class="vd-center" data-max="fib-377">…</div>

<!-- center content both axes -->
<div class="vd-center" data-axis="both">…</div>
AttributeValuesEffect
data-maxfib-377 / fib-610 / fib-987Max width; the box auto-centers via margin-inline.
data-axisboth / horizontal / verticalCenter the content via flex on the chosen axis.

Frame — a fixed aspect-ratio box (golden by default)

.vd-frame locks an element to an aspect ratio; image, video, and canvas children object-fit: cover to fill it. The default ratio is the golden ratio.

golden · 1.618
square · 1:1
16:9
<div class="vd-frame" data-ratio="golden">
  <img src="hero.jpg" alt="">
</div>
AttributeValuesEffect
data-ratiogolden / golden-portrait / square / 16-9 / 4-3 / 3-2 / 21-9The locked aspect ratio (default golden = 1.618).
Cover — a min-height region that centers its content

.vd-cover fills a minimum height (a full screen by default) and vertically centers whatever it holds — heroes, empty states, splash sections. The demo caps the height for illustration.

Vertically centered min-height region 
<div class="vd-cover" data-min="screen" data-gap="fib-8">
  <h1>Centered hero</h1>
</div>
AttributeValuesEffect
data-minscreen / half / fib-610 / fib-987Minimum height (default screen = 100vh).
data-gapfib-3 … fib-34Gap between stacked children.
Switcher — row that stacks at a threshold (no media query)

.vd-switcher lays its children in a row until the container drops below a Fibonacci threshold, then switches them to a stack — purely in CSS, responsive to the container rather than the viewport. Narrow your window to watch these stack.
